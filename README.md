# Sales Analytics Dashboard

## 📊 Project Overview

Sales Analytics Dashboard is a professional web-based dashboard created to analyze sales performance and present important business insights in a clear and interactive format.

The dashboard is based on a sales dataset analyzed using Excel, Power BI and SQL.

## 🚀 Live Dashboard

👉 https://shivam-rai6206.github.io/sales-analytics-dashboard/

## 🛠️ Tools & Technologies

- HTML
- CSS
- JavaScript
- Excel
- Power BI
- SQL

## 📈 Dashboard Features

- Total Sales overview
- Total Profit overview
- Regional Sales Analysis
- Payment Method Analysis
- Key Business Insights
- Dark Mode
- Responsive Design
- Professional dashboard layout
